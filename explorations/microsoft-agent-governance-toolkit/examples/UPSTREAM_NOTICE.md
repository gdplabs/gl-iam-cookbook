# Curated upstream examples

This directory contains unmodified, selected examples copied from the Microsoft
Agent Governance Toolkit (AGT) commit
[`1a896e70aca8ced2a243d5702cb0359d4ded5c50`](https://github.com/microsoft/agent-governance-toolkit/tree/1a896e70aca8ced2a243d5702cb0359d4ded5c50),
under the upstream MIT License. They are kept here so the exploration's runners
can execute the exact selected examples after `setup_demo.ps1` installs the
matching AGT policy-engine runtime.

Curated source paths:

- `acs-email-tool/` ← `examples/acs-email-tool/`
- `support_agent/` ← `policy-engine/examples/support_agent/`
